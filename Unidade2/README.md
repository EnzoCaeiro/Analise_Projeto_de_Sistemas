## 📖 Conteúdo da aula

Nesta unidade, foram abordados os principais conceitos relacionados à Análise e ao Projeto de Sistemas de Informação, com foco nos fundamentos da Engenharia de Software e na utilização de ferramentas para modelagem de sistemas.

A aula apresentou uma visão geral sobre a importância da análise na identificação das necessidades dos usuários e de como essas necessidades podem ser transformadas em requisitos que orientem o desenvolvimento de um sistema.

## 📋 Atividade realizada

Como atividade prática desta unidade, foi elaborado o levantamento de requisitos do **Sistema de Biblioteca**.

O objetivo da atividade foi registrar, de forma estruturada, as funcionalidades que o sistema deve oferecer e as características de qualidade que devem ser atendidas.

O sistema terá como finalidade gerenciar:

- Cadastro de usuários.
- Cadastro de livros.
- Empréstimos.
- Devoluções.
- Multas.
- Consultas de disponibilidade.

### Requisitos funcionais

Os requisitos funcionais descrevem as funcionalidades e os serviços oferecidos pelo sistema. Entre os requisitos registrados estão:

- Cadastrar usuário.
- Cadastrar livro.
- Realizar empréstimo.
- Registrar devolução.
- Calcular multa.
- Consultar disponibilidade de livro.

Cada requisito foi identificado com um código único, uma descrição, uma prioridade, critérios de aceitação e um exemplo de utilização.

### Requisitos não funcionais

Os requisitos não funcionais apresentam características de qualidade, restrições e condições que o sistema deve atender. Entre os registrados estão:

- Segurança.
- Usabilidade.
- Desempenho.
- Disponibilidade.
- Integridade dos dados.

### Entregáveis da atividade

- Identificação do sistema.
- Pelo menos cinco requisitos funcionais.
- Pelo menos três requisitos não funcionais.
- Prioridade de cada requisito.
- Critérios de aceitação.
- Exemplos de utilização.
- Identificação dos integrantes do grupo.

A ficha produzida nesta unidade servirá como base para as próximas etapas da disciplina, especialmente para a identificação e especificação dos casos de uso.
